ئەم فایلە UI ـی بنەڕەتیی تەواوی Phase 1 ـە؛ Google button ـەکە ئێستا placeholder ـە، چونکە Google token دەبێت لە backend پشتڕاست بکرێتەوە، نەک تەنها بە JavaScript ـی browser. Google بۆ ئەم flow ـە server-side handling و verification ـی ID token باس دەکات. لە هەنگاوی دواتر "styles.css" دەدەم و هەموو ئەم UI ـە بە دیزاینی واقعی، animation، responsive mobile/desktop و dark/light دەکەین؛ پاشان "app.js" کە navigation، Google-state، builder، preview و Admin data ـی test بەڕێوە دەبات.
